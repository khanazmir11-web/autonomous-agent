# Inbox (owner → agent)

Owner: write new messages at the **bottom** of this file, with a date. Examples:
- `2026-10-10: APPROVED — create payment link for "X" at $9.`
- `2026-10-10: Real credit left from my Usage page: $83.20`
- `2026-10-10: Payment link: https://buy.stripe.com/...`
- `2026-10-10: Don't pursue idea #2.`

The agent reads everything below the last `---handled---` line and adds a new
`---handled---` line after acting on it.
